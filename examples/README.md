# Examples

These examples show the narrow reuse-evidence contract without an agent SDK,
network service, cache, or execution authority.

```powershell
python examples/basic.py
python examples/interop_cli_producer.py receipt.json
python examples/interop_consumer.py receipt.json
```

The MCP adapter is documented separately in [`docs/MCP_INTEROP.md`](../docs/MCP_INTEROP.md).
